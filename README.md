# OLYSS — Construction & Development

A premium construction and development web experience focused on
architecture, craftsmanship, engineering precision, and long-term value.

## Features

- Premium architectural design
- Responsive layout
- Construction/project showcase
- Smooth scrolling
- Scroll-based animations
- Interactive navigation
- Responsive mobile experience
- Editorial-style typography
- Project presentation sections
- Contact/CTA sections

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- Lenis

## Design Direction

The design follows an architectural-editorial direction with a restrained
palette of ivory, charcoal, graphite, concrete gray, and muted bronze.

The goal is to communicate:

**Trust · Craftsmanship · Precision · Quality · Long-Term Value**
